# Step 11 — Accessibility Review

## Objective

Ensure the experience remains usable and understandable without relying on visual perfection or motion.

## Inputs

- Running implementation

## Actions

Review:

- semantic HTML
- heading hierarchy
- keyboard navigation
- focus visibility
- form labels
- interactive controls
- alt text
- contrast
- link/button semantics
- reduced motion
- content hidden/revealed by animation

## Reduced Motion

Verify that:

- unnecessary parallax is removed or simplified
- cinematic transitions are reduced
- content remains available
- interaction meaning is preserved

## Critical Questions

- Can the primary journey be completed with keyboard only?
- Can the page be understood without animation?
- Are interactive elements semantically correct?
- Is important content visually hidden in a way that harms access?

## Output

An accessibility review containing:

- Passed checks
- Issues
- Severity
- Recommended fixes

## Stop Conditions

Fix issues that prevent access to core content or actions.

## Self-Review

Navigate the experience conceptually without:

- mouse
- animation
- color alone

Identify what breaks.
